React 应用性能优化清单（实战版）

React 性能问题通常来自不必要渲染、过大首屏包、低效数据请求和阻塞主线程任务。优化要从“测量”开始，而不是先改代码。

1. 渲染层优化

  • 使用 React.memo 控制纯展示组件重复渲染。
  • 对函数 props 使用 useCallback，避免子组件误触发更新。
  • 复杂计算用 useMemo 缓存，并控制依赖项准确性。
  • 长列表采用虚拟滚动（如 react-window）。

2. 资源与构建优化

  • 启用路由级动态导入：const Page = lazy(() => import('./Page'))。
  • 分析打包产物，拆分大体积第三方库。
  • 静态资源开启缓存与压缩（brotli/gzip）。

3. 数据请求优化

  • 对接口进行去重和缓存，减少重复请求。
  • 长耗时接口增加骨架屏与超时重试。
  • 按页面可见性加载数据，避免“过度预取”。

4. 监控指标与闭环

建议至少跟踪以下指标：FCP、LCP、CLS、INP、JS Heap、路由切换耗时。性能治理是持续工程：发现热点页面 → 分析火焰图 → 小步发布 → 回归验证。

  console.log(`[${id}] ${phase}: ${actualDuration}ms`);
}
